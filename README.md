## 🚀 How to View the Website
You can view the website right away without installing any tools:
1. Open this folder: `c:\Users\RCP\Desktop\project`
2. Double-click **`index.html`** to open it in your browser (Chrome, Edge, Firefox, etc.).
3. Or, if using VS Code, right-click `index.html` and click **"Open with Live Server"**.

---

## 🛠️ How to Customize Your Information

All content is inside [`index.html`](index.html). Search for `<!-- CUSTOMIZE:` comments in the code to update:

1. **Contact Details & Socials**:
   - Update your email: change `khusheepatil@example.com` to your real email.
   - Update your GitHub and LinkedIn profile URLs.
   - Update your location in the contact section.

2. **Education Details**:
   - In the `#education` section, update your college/university name, current year/semester, and CGPA/percentage if you wish.

3. **Projects**:
   - In the `#projects` section, replace the project titles, descriptions, and add your real GitHub repository links.

4. **Resume**:
   - Place your resume PDF (e.g. `resume.pdf`) inside this folder and link it to the button in the navigation or hero section.

## 🎨 Tech Stack
- **HTML5 & Vanilla JavaScript**: Zero dependencies, instant loading.
- **Tailwind CSS (CDN)**: Modern responsive design with custom dark palette.
- **Font Awesome 6**: Vector icons for socials and tech.
- **Google Fonts**: Plus Jakarta Sans & JetBrains Mono.
